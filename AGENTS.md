Development Rules

- stay on 1 font and black or white text only unless i specify.
- Remove unused variables, functions, imports, and styles.
- Avoid duplicate code. Reuse functions and components when appropriate.
- Use meaningful and understandable variable, function, and class names.
- Maintain consistent spacing, margins, and padding throughout the website.
- Handle errors and unexpected user actions properly.
- Ensure the website works on desktop, ignore responsiveness on mobile.
- Maintain consistent layouts across different screen sizes.
- Follow a consistent naming convention.
- Make changes without unnecessarily modifying unrelated code.
- Prioritize readability over overly complicated solutions.
